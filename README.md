# 🏺 Ceramic Shop

A comprehensive Database Management System (DBMS) project for managing a ceramic shop's operations.

## 📋 Overview

Ceramic Shop is a full-featured DBMS application designed to streamline the management of a ceramic business. This project handles inventory management, customer transactions, order processing, and business analytics for a ceramic retail shop.

## 🎯 Features

- **Inventory Management** - Track ceramic products, stock levels, and warehouse locations
- **Customer Management** - Maintain customer profiles and purchase history
- **Order Processing** - Create, track, and manage customer orders
- **Sales Analytics** - Generate reports and insights on business performance
- **Database Operations** - Full CRUD operations on all core entities

## 🚀 Getting Started

### Prerequisites

- PHP 7.4 or higher
- MySQL/MariaDB database server
- Web server (Apache, Nginx, etc.)
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Pranjalstack/Ceramic-shop.git
cd Ceramic-shop
```

2. Set up your database:
```bash
# Create a new database
mysql -u root -p < database.sql
```

3. Configure database connection:
   - Update database credentials in the configuration file

4. Start your web server and navigate to the application
